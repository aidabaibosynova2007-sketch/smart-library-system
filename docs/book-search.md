# Кітаптарды іздеу функциясы

Smart Library жүйесінде оқырман кітаптарды атауы, авторы және жанры бойынша іздей алады.

## Іздеу мүмкіндіктері
- Кітап атауы бойынша іздеу.
- Автор бойынша іздеу.
- Жанр бойынша іздеу.
- Кітаптың қолжетімділігін тексеру.
- Кітаптың орналасқан залын және сөресін көрсету.

## SQL сұранысы

```sql
SELECT *
FROM Books
WHERE title LIKE '%Абай%'
   OR author LIKE '%Абай%'
   OR genre LIKE '%Роман%';
```

Бұл сұраныс кітаптарды берілген іздеу шарттарына сәйкес табады.
